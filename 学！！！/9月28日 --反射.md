# 反射 

## 定义
反射允许对**成员变量、成员方法、构造方法**的信息进行**编程访问**。

拆开读这句话：
- 操作对象：成员变量、成员方法、构造方法（就这三样）
- 关键动作：**编程访问** —— 不是用眼睛看，而是在**代码里**把它们拿到手、改掉、调起来

## 两个阶段：先「获取」，再「解剖」

| 阶段 | 含义 | 对应课件的两列 |
|---|---|---|
| **获取** | 把目标"拿到手" | 获取 Class 对象 / 字段 / 构造方法 / 成员方法 |
| **解剖** | 把目标"拆开看、动手用" | 拿修饰符、名字、形参…；赋值取值、创建对象、运行方法 |

顺序不能反：**没获取，就没得解剖。**&#8203;

## 一个入口 + 三件套

| 目标 | 对应类 | 能做的事 |
|---|---|---|
| **入口** | `Class` | 一切从它开始，反射的唯一钥匙 |
| 字段（成员变量） | `Field` | 修饰符 / 名字 / 类型；**赋值 / 获取值** |
| 构造方法 | `Constructor` | 修饰符 / 名字 / 形参；**创建对象** |
| 成员方法 | `Method` | 修饰符 / 名字 / 形参 / 返回值 / 抛出的异常 / 获取注解；**运行方法** |

包路径：三个类都在 `java.lang.reflect`；`Class` 在 `java.lang`（所以不用导包）。

## 为什么需要反射？（这页没说，但必须懂）

平时写代码是这样：
    Person p = new Person();

**类名、字段名、方法名，在编译的时候就全写死了。**&#8203;

反射专门解决"**编译期根本不知道要操作哪个类**"的场景：
- 类名是从**配置文件 / 注解**里读来的字符串，运行时才加载这个类
- 拿到之后动态地问它：你有哪些字段？哪些方法？然后动态赋值、动态调用

👉 **Spring、MyBatis 这些框架，本质就是靠反射去"读别人的类"。**&#8203; 这就是它必须学的原因。

## 一句话记
**反射 = 程序在运行时"反过来"看见自己的结构。**&#8203;
**入口是 Class 对象，出口是三件套：Field 改字段、Constructor 造对象、Method 调方法。**&#8203;

# 获取 Class 对象的三种方式

## 三种写法（对应课件代码）

| 方式 | 写法 | 什么时候用 |
|---|---|---|
| ① | `Class.forName("全类名")` | **最常用**，类名写在配置里，运行时才加载 |
| ② | `类名.class` | **一般当参数传递**用，编码最简单 |
| ③ | `对象.getClass()` | 已经**先有了对象**，想反查它的类 |

## 完整代码
```java
    public class Demo {
        public static void main(String[] args) throws ClassNotFoundException {
            // 1. 第一种方式：全类名 = 包名 + 类名（最常用）
            Class clazz1 = Class.forName("com.itheima.myreflect1.Student");

            // 2. 第二种方式：类名.class（一般当参数传递）
            Class clazz2 = Student.class;

            // 3. 第三种方式：先有对象，再反查
            Student s = new Student();
            Class clazz3 = s.getClass();

            System.out.println(clazz1 == clazz2);   // true
            System.out.println(clazz2 == clazz3);   // true
        }
    }
```

## 为什么 `==` 都是 true？（核心理解）

因为**一个类在 JVM 中只会被加载一次**，加载时只创建**一份** Class 对象。

- 三种方式拿到的**是同一个对象**，不是内容相同的三个对象
- 所以能用 `==` 直接比，结果当然是 `true`
- 也正因为如此，Class 对象**不是你 new 出来的**，是 JVM 加载类的时候替你造的

## 易错点
1. **"全类名" = 包名 + 类名**，别只写 `"Student"`，必须写 `"com.itheima.myreflect1.Student"`
2. `Class.forName(...)` 会抛 **`ClassNotFoundException`**（编译时异常），必须 `throws` 或 try-catch —— 因为字符串里的类名写错编译器也发现不了
3. 方式③ 是"**绕了一圈**"：得先 new 对象才能拿 Class，而反射本来就是为了不 new 对象 —— 所以它用得最少
4. 这三个拿到的都是**同一个类**的 Class；想拿父类用 `clazz.getSuperclass()`

## 一句话记
**forName 靠字符串最灵活，`.class` 最省事专门传参，`getClass()` 得先有对象最被动。**&#8203;
**三条路，同一个终点。**&#8203;

# 利用反射获取构造方法Constructors

## 一、Class 类：四个获取方法

| 方法                                          | 返回  | 能拿到什么                     |
| ------------------------------------------- | --- | ------------------------- |
| `getConstructors()`                         | 数组  | 所有 **public** 构造方法        |
| `getDeclaredConstructors()`                 | 数组  | **所有**构造方法（**含 private**） |
| `getConstructor(Class<?>... types)`         | 单个  | 指定的 **public** 构造方法       |
| `getDeclaredConstructor(Class<?>... types)` | 单个  | 指定的构造方法（**含 private**）    |

## 两条规律（本章通用，Field / Method 一模一样）

1. **带 `s` → 返回数组（拿一堆）；不带 `s` → 返回单个**
2. **带 `Declared` → 连私有的一起拿；不带 → 只认 public**

👉 后面学 Field、Method 时，把这两条套上去就行，不用重新记。

## 二、`Class<?>... parameterTypes` 怎么填

它要的是**形参类型的 Class 对象**，用来告诉它"我要哪个构造方法"：

| 目标构造方法 | 怎么写 |
|---|---|
| 无参构造 | `getDeclaredConstructor()` 空着就行 |
| `Student(String name)` | `getDeclaredConstructor(String.class)` |
| `Student(String name, int age)` | `getDeclaredConstructor(String.class, int.class)` |

⚠ 基本类型写 `int.class`，**不是** `Integer.class`。

## 三、Constructor 类：造对象

| 方法 | 作用 |
|---|---|
| `T newInstance(Object... initargs)` | 按这个构造方法**创建对象**，参数传的是**实参** |
| `setAccessible(boolean flag)` | 传 `true` = **取消访问检查**（俗称"暴力反射"） |

## 四、完整写法
```java
    Class clazz = Class.forName("com.itheima.myreflect2.Student");

    // 1. 拿 public 无参构造
    Constructor con1 = clazz.getConstructor();
    Student s1 = (Student) con1.newInstance();

    // 2. 拿 public 带参构造
    Constructor con2 = clazz.getConstructor(String.class, int.class);
    Student s2 = (Student) con2.newInstance("张三", 23);

    // 3. 拿私有构造 —— 必须先取消访问检查
    Constructor con3 = clazz.getDeclaredConstructor(String.class);
    // 少这行会抛 IllegalAccessException
    con3.setAccessible(true); 
    Student s3 = (Student) con3.newInstance("李四");
```
## 易错点
1. 用 `getConstructor` 去拿**私有**构造 → 直接抛 `NoSuchMethodException`（它只认 public）
2. 私有构造拿到手**还得** `setAccessible(true)`，否则 `newInstance` 时抛 `IllegalAccessException`
3. `newInstance` 里的参数是**实参**（`"张三", 23`），要和构造方法的形参类型、个数对得上
4. `setAccessible(true)` 只是**关掉访问检查**，并没有把 private 变成 public
5. `Constructor`、`Field`、`Method` **都有** `setAccessible` —— 因为都继承自 `AccessibleObject`
6. 别和 `Class` 的 `newInstance()` 混：那个已过时（Java 9+），现在统一用 `Constructor.newInstance()`

## 一句话记
**带 s 拿一堆，带 Declared 连私有一起拿；`newInstance` 造对象，碰私有先 `setAccessible(true)`。**&#8203;

# 利用反射获取成员变量（Field）

## 一、Class 类：四个获取方法

| 方法 | 返回 | 能拿到什么 |
|---|---|---|
| `getFields()` | 数组 | 所有 **public** 成员变量 |
| `getDeclaredFields()` | 数组 | **所有**成员变量（**含 private**） |
| `getField(String name)` | 单个 | 指定的 **public** 成员变量 |
| `getDeclaredField(String name)` | 单个 | 指定的成员变量（**含 private**） |

规律和 Constructor 完全一致：**带 s 拿一堆，带 Declared 连私有一起拿。**&#8203;
（课件顶部批注写的就是这个："加 s 是获取所有，不加是获取单个"）

## 二、⚠ 和 Constructor 的唯一区别：参数不一样

| | 单个获取时传什么 |
|---|---|
| `getDeclaredConstructor(`**`Class<?>...`**`)` | 传**形参类型的 Class 对象**（如 `String.class`） |
| `getDeclaredField(`**`String`**`)` | 传**变量名的字符串**（如 `"name"`） |

**构造方法靠"参数类型"区分，字段靠"名字"区分** —— 一个类里字段名是唯一的，不会重名。

## 三、Field 类：赋值 / 取值

| 方法 | 作用 |
|---|---|
| `void set(Object obj, Object value)` | 给 **obj 对象**的这个字段赋值为 value |
| `Object get(Object obj)` | 取出 **obj 对象**的这个字段的值 |

## 四、为什么 set / get 一定要传对象？（理解难点）

Field 对象只是"**字段的说明书**"，它只知道：
- 这个字段叫什么名字
- 是什么类型
- 有什么修饰符

**但它不知道自己属于哪个对象。**&#8203; 一个 `Student` 类可以 new 出 100 个对象，每个对象的 `name` 都不一样。

所以要操作时必须告诉它： **“对哪个对象的这个字段下手”** &#8203; —— 这就是第一个参数 `Object obj` 的意义。

## 五、完整写法
```java
    Class clazz = Class.forName("com.itheima.myreflect3.Student");

    // 1. 先造一个对象（用前面的构造方法）
    Constructor con = clazz.getDeclaredConstructor();
    con.setAccessible(true);
    Student s = (Student) con.newInstance();
 
    // 2. 拿字段（私有字段要开权限）
    Field nameField = clazz.getDeclaredField("name");
    nameField.setAccessible(true);

    // 3. 赋值 / 取值 —— 注意第一个参数传的是对象 s
    nameField.set(s, "张三");              // 给 s 的 name 赋值
    Object value = nameField.get(s);       // 取出 s 的 name 值
    System.out.println(value);             // 张三
```
## 易错点
1. `getDeclaredField` 的参数是**变量名字符串**，别顺手写 `String.class`（那是 Constructor 的写法）
2. `set(s, "张三")` 的第一个参数是**具体对象**，不是 Class 对象
3. 私有字段一样要 `setAccessible(true)`，否则抛 `IllegalAccessException`
4. `get()` 返回的是 **Object**，用之前记得强转
5. **静态字段**不属于任何对象，所以可以传 `null`：`field.set(null, 值)`
6. 课件标题写的"Field类中用于**创建对象**的方法"是笔误，应为"**&#8203;操作成员变量**的方法"

## 一句话记
**构造方法按"参数类型"找，成员变量按"名字"找；`set` / `get` 第一个参数永远是"哪个对象"。**&#8203;

# 利用反射获取成员方法（Method）

## 一、Class 类：四个获取方法

| 方法 | 返回 | 能拿到什么 |
|---|---|---|
| `getMethods()` | 数组 | 所有 **public** 方法，**包括继承来的** |
| `getDeclaredMethods()` | 数组 | 所有方法，**不包括继承的**（只本类声明） |
| `getMethod(String name, Class<?>... types)` | 单个 | 指定的 **public** 方法 |
| `getDeclaredMethod(String name, Class<?>... types)` | 单个 | 指定的方法（**含 private**） |

**Method 特有的坑**：`getMethods()` 会把从 `Object` 继承的一堆方法也带出来（`wait`、`equals`、`toString`、`getClass`…），看着很乱。只想看本类自己写的 → 用 `getDeclaredMethods()`。

## 二、⭐ 三件套参数对比（本章最值得记的一张表）

| 目标 | 单个获取怎么写 | 为什么 |
|---|---|---|
| 构造方法 | `getDeclaredConstructor(`**`Class<?>...`**`)` | 构造方法名字固定是类名，只能靠**参数类型**区分 |
| 成员变量 | `getDeclaredField(`**`String name`**`)` | 字段**不会重名**，给名字就够 |
| 成员方法 | `getDeclaredMethod(`**`String name, Class<?>...`**`)` | 方法会**重载**，必须"名字 + 参数类型"一起给 |

一句话：**构造看类型，字段看名字，方法两个都要。**&#8203;

## 三、Method 类：运行方法

`Object invoke(Object obj, Object... args)`

| 参数 / 返回值 | 含义 |
|---|---|
| 参数一 `obj` | **用哪个对象**调用这个方法（和 Field 一样，必须给对象） |
| 参数二 `args` | 调用时传的**实参**（方法没参数就不写） |
| 返回值 | 方法的返回值；**方法没有返回值就是 `null`** |

## 四、完整写法
```java
    Class clazz = Class.forName("com.itheima.myreflect4.Student");

    // 先造对象
    Constructor con = clazz.getDeclaredConstructor();
    con.setAccessible(true);
    Student s = (Student) con.newInstance();

    // 1. 拿无参方法：只要名字
    Method m1 = clazz.getDeclaredMethod("getName");
    Object r1 = m1.invoke(s);                  // 相当于 s.getName()

    // 2. 拿带参方法：名字 + 形参类型
    Method m2 = clazz.getDeclaredMethod("setName", String.class);
    m2.invoke(s, "张三");                       // 相当于 s.setName("张三")，无返回值 → null

    // 3. 私有方法要先开权限
    Method m3 = clazz.getDeclaredMethod("study");
    m3.setAccessible(true);
    m3.invoke(s);
```
## 易错点
1. `getDeclaredMethod` 必须**同时给名字和形参类型**，只给名字找不到重载方法 → 抛 `NoSuchMethodException`
2. `invoke` 的第一个参数是**对象**；调**静态方法**时传 `null`
3. `invoke` 返回的是 **Object**，无返回值的方法返回 **null**（不是不返回）
4. 私有方法同样要 `setAccessible(true)`
5. 如果被调用的方法自己抛了异常，`invoke` 会把它包成 **`InvocationTargetException`** 再抛出来 —— 排错时要看 `getCause()`
6. 课件标题"Method类中用于**创建对象**的方法"是笔误，应为"**&#8203;运行方法**的方法"

## 一句话记
**方法重载 → 找方法必须"名字 + 参数类型"；`invoke(对象, 实参)` 就是"用这个对象跑这个方法"。**&#8203;
