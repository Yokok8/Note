# 不可变集合

**不可变集合**：不能被修改的集合。

两个"不能"：
- ❌ 不能改长度 → 不能 add / remove
- ❌ 不能改内容 → 不能 set / put

✅ 能做的只有"读"：get、遍历、for-each

## 不可变集合的使用场景

1. **数据不能改** → 防御性拷贝到不可变集合里
2. **集合交给不可信的库** → 用不可变形式最安全

> 一句话：**不想让别人改你的数据**，就用不可变集合。

🎴 例子：54 张扑克牌就是不可变的 —— 牌的种类固定，不会变

## 创建不可变集合的写法

JDK 9+ 提供了一个超简单的方法：`of()`

| 方法 | 说明 |
|------|------|
| `List.of(元素...)` | 创建不可变 List |
| `Set.of(元素...)` | 创建不可变 Set |
| `Map.of(键值对...)` | 创建不可变 Map |

⚠️ 注意：创建后**不能 add、不能 remove、不能改内容**

### 快速例子
```java
List<String> list = List.of("A", "B", "C");
Set<Integer> set = Set.of(1, 2, 3);
Map<String, Integer> map = Map.of("a", 1, "b", 2);
```

### Set.of 的细节

- ❌ 元素不能重复 → 重复会报错 `IllegalArgumentException`
- ❌ 元素不能为 null
- ✅ 顺序不保证（Set 本来无序）

```java
Set<String> set = Set.of("A", "B", "C");
Set<String> err = Set.of("A", "A");  // ❌ 报错，A 重复了
```

### Map.of 的细节（重点，坑最多）

1. 参数是**成对**的：键、值、键、值...
2. **最多 10 对**（20 个参数），超过要用 `Map.ofEntries()`
3. ❌ key 不能重复
4. ❌ key 和 value 都不能为 null

```java
// 1. 准备好你的 Map
HashMap<String, String> hm = new HashMap<>();
hm.put("张三", "南京");
hm.put("李四", "北京");
hm.put("王五", "上海");
// ... 假设已经超过 10 对

// 2. 转不可变
Set<Map.Entry<String, String>> entries = hm.entrySet();//Set<Entry>，类型不对
Map.Entry[] arr = new Map.Entry[0];
Map.Entry[] arr2 = entries.toArray(arr);//toArray(有参)转成 Entry[]，类型对齐
Map<String, String> immu = Map.ofEntries(arr2);// 得到不可变 Map

//简单合在一起
Map<Object,Object> map1 =Map.ofEntries(map.entrySet().toArray(new Map.Entry[0]));
```



# 不可变集合 · 总结

## 1. 不可变集合的特点
- 定义完成后**不可以修改**、**不可以添加**、**不可以删除**

## 2. 如何创建
- `List` / `Set` / `Map` 接口中，都存在 `of()` 方法 → 创建不可变集合

## 3. 三种方式的细节

| 接口 | 关键限制 |
|------|----------|
| **List** | 直接用，没特殊坑 |
| **Set** | 元素**不能重复** |
| **Map** | 元素不能重复；**键值对最多 10 个** |

⚠️ Map 超过 10 对 → 改用 `Map.ofEntries(Map.entry(k,v), ...)` 或 `Map.ofEntries(set.toArray(new Map.Entry[0]))`
