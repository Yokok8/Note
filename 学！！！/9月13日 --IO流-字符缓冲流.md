# 字符缓冲流构造方法

| 构造 | 说明 |
|------|------|
| `public BufferedReader(Reader r)` | 把**基本流**变成**高级流** |
| `public BufferedWriter(Writer r)` | 把**基本流**变成**高级流** |

## 🔥 原理（跟字节缓冲流一样）

> **底层自带了长度为 8192 的缓冲区提高性能**



# 字符缓冲流的特有方法

## 字符缓冲输入流特有方法

| 方法 | 说明 |
|------|------|
| `public String readLine()` |读取一行数据，**如果没有数据可读了，会返回 null** |
# readLine() 标准模板

```java
//1.创建字符缓冲输入流的对象
BufferedReader br = new BufferedReader(new FileReader("myio\\\\a.txt"));

//2.读取数据
String line;
while ((line = br.readLine()) != null) {
    System.out.println(line);
}

// 关流
br.close();
```
