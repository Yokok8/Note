# Commons-io（IO 界的"外挂工具包"）

## 是什么

**Apache 开源基金组织**提供的一组有关 IO 操作的开源工具包。

> ⚠️ 注意：它是**第三方 jar 包**，不是 JDK 自带的，需要单独引入。

## 作用

**提高 IO 流的开发效率** —— 把原本要写几十行的 IO 操作，压缩成一行。

---

# FileUtils 常见方法（文件 / 文件夹相关）

| 方法 | 说明 |
|---|---|
| `static void copyFile(File srcFile, File destFile)` | 复制文件 |
| `static void copyDirectory(File srcDir, File destDir)` | 复制文件夹（**内容**搬过去） |
| `static void copyDirectoryToDirectory(File srcDir, File destDir)` | 复制文件夹（**连自己一起**搬过去） |
| `static void deleteDirectory(File directory)` | 删除文件夹（**连文件夹一起删**） |
| `static void cleanDirectory(File directory)` | 清空文件夹（**文件夹保留**） |
| `static String readFileToString(File file, Charset encoding)` | 读取文件数据变成字符串 |
| `static void write(File file, CharSequence data, String encoding)` | 写出数据 |

---

# IOUtils 常见方法（流相关）

| 方法 | 说明 |
|---|---|
| `static int copy(InputStream input, OutputStream output)` | 复制文件，**返回拷贝的字节数** |
| `static long copyLarge(Reader input, Writer output)` | 复制大文件，**返回 long** |
| `static String readLines(Reader input)` | 读取数据 |
| `static void write(String data, OutputStream output)` | 写出数据 |

---

## 先分清：FileUtils 还是 IOUtils？

| | FileUtils | IOUtils |
|---|---|---|
| 操作对象 | **File 对象** | **流对象**（InputStream/OutputStream/Reader/Writer） |
| 什么时候用 | 有文件路径，直接操作磁盘文件 | 已经拿到流了（网络流、内存流、包装流） |
| 会不会自动关流 | ✅ 内部自己管 | ❌ **不关流，要你自己关** |

> **一句话：有 File 用 FileUtils，有流用 IOUtils。**&#8203;

# Hutool 工具包（国产"开发利器"）

> **一句话定位**：Hutool 是一个**国产 Java 工具类大全**（组织：dromara），把日常开发要用的工具类全塞进了一个 jar 包里。
> 口号： **“一个依赖包，半天开发变半天”** &#8203;。

## IO 相关类（本页重点）

| 相关类 | 说明 |
|---|---|
| `IoUtil` | 流操作工具类 |
| `FileUtil` | 文件读写和操作的工具类 |
| `FileTypeUtil` | 文件类型判断工具类 |
| `WatchMonitor` | 目录、文件监听 |
| `ClassPathResource` | 针对 ClassPath 中资源的访问封装 |
| `FileReader` | 封装文件读取 |
| `FileWriter` | 封装文件写入 |
