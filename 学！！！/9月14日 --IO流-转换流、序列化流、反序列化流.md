# 转换流的两大作用

## 定义
转换流是**字符流和字节流之间的桥梁**

## 两大作用

| 作用 | 内容 | 现状 |
|------|------|------|
| **作用1** | **指定字符集读写** | ⚠️ **淘汰了**（JDK 11+ FileReader/FileWriter 可直接传字符集）|
| **作用2** | **字节流想要使用字符流中的方法** | ✅ **还在用**（重点）|
# 实战：把 GBK 文件转成 UTF-8

## 需求
将本地文件中的 GBK 文件，转成 UTF-8

## 方案1：JDK 11 以前（用转换流，已淘汰）

```java
InputStreamReader isr = new InputStreamReader(
    new FileInputStream("myio\\\\b.txt"), "GBK");      // 按 GBK 读
OutputStreamWriter osw = new OutputStreamWriter(
    new FileOutputStream("myio\\\\d.txt"), "UTF-8");   // 按 UTF-8 写

int b;
while ((b = isr.read()) != -1) {
    osw.write(b);
}
osw.close();
isr.close();
```

## 方案2：JDK 11+ 替代方案（FileReader/FileWriter 直接传 Charset ✅）

```java
FileReader fr = new FileReader("myio\\\\b.txt", Charset.forName("GBK"));      // 按 GBK 读
FileWriter fw = new FileWriter("myio\\\\e.txt", Charset.forName("UTF-8"));    // 按 UTF-8 写

int b;
while ((b = fr.read()) != -1) {
    fw.write(b);
}
fw.close();
```


# 实战：字节流读文件，每次读一整行，不能乱码

## 需求分析（黑马注释的重点）

// 1. 字节流在读取中文的时候，是会出现乱码的，但是字符流可以搞定
// 2. 字节流里面是没有读一整行的方法的，只有字符缓冲流才能搞定

→ 结论：需要 **字节流 + 转换流 + 字符缓冲流** 三层配合

---

## 写法1：分步版（容易理解）

```java
FileInputStream fis = new FileInputStream("myio\\\\a.txt"); // 字节流
InputStreamReader isr = new InputStreamReader(fis);          // 转换流：字节 → 字符
BufferedReader br = new BufferedReader(isr);                 // 缓冲流：提供 readLine

String str = br.readLine();     // 一次读一行 ✅ 不乱码 ✅
System.out.println(str);
br.close();
```

## 写法2：套娃版（一行搞定，实际开发常用 ✅）

```java
BufferedReader br = new BufferedReader(
    new InputStreamReader(
        new FileInputStream("myio\\\\a.txt")));

String line;
while ((line = br.readLine()) != null) {
    System.out.println(line);
}
br.close();
```

# 序列化流 / 对象操作输出流（ObjectOutputStream）

## 作用
**可以把 Java 中的对象写到本地文件中**

## 构造方法

| 构造方法 | 说明 |
|---------|------|
| `public ObjectOutputStream(OutputStream out)` | 把**基本流包装成高级流** |

## 成员方法

| 方法                                          | 说明                  |
| ------------------------------------------- | ------------------- |
| `public final void writeObject(Object obj)` | 把**对象序列化（写出）到文件中去** |

## 序列化流的小细节

### ⚠️ 报错场景
使用对象输出流将对象保存到文件时会出现 **NotSerializableException** 异常

### ✅ 解决方案
**需要让 JavaBean 类实现 Serializable 接口**

# 序列化流实战模板

## 完整代码（4 步模板）

```java
// 1. 创建对象
Student stu = new Student("zhangsan", 23);

// 2. 创建序列化流的对象/对象操作输出流
ObjectOutputStream oos = new ObjectOutputStream(
    new FileOutputStream("myio\\\\a.txt"));

// 3. 写出数据
oos.writeObject(stu);

// 4. 释放资源
oos.close();
```

# 反序列化流 / 对象操作输入流（ObjectInputStream）

## 作用
可以把**序列化到本地文件中的对象**，**读取到程序中来**

## 构造方法

| 构造方法 | 说明 |
|---------|------|
| `public ObjectInputStream(InputStream out)` | 把基本流变成高级流 |

## 成员方法

| 方法 | 说明 |
|------|------|
| `public Object readObject()` | 把序列化到本地文件中的对象，**读取到程序中来** |


# 反序列化流实战模板

## 需求
利用反序列化流/对象操作输入流，把文件中的对象读到程序当中

## 完整代码（4 步模板）

```java
// 1. 创建反序列化流的对象
ObjectInputStream ois = new ObjectInputStream(
    new FileInputStream("myio\\\\a.txt"));

// 2. 读取数据（返回 Object，必须强转成 Student）
Student o = (Student) ois.readObject();

// 3. 打印对象
System.out.println(o);

// 4. 释放资源
ois.close();
```


# 版本号（serialVersionUID）

## 定义方式

```java
public class Student implements Serializable {
    private static final long serialVersionUID = 1L;  // ← 版本号

    private String name;
    private int age;
    private String address;
}
```

## 核心机制

```
序列化时：对象 + 类的版本号（1）→ 一起写进文件
反序列化时：文件里的版本号（1） ↔ 类里的版本号（1）→ 比对
         ├─ 一致 ✅ → 还原成功
         └─ 不一致 ❌ → InvalidClassException
```


# transient（瞬态关键字）

## 作用
**不会把当前属性序列化到本地文件当中**

## 用法

```java
private transient String address;  // 这个字段不参与序列化
```


# 需求：将多个自定义对象序列化到文件中，但是对象的个数不确定，该如何操作呢？

## 💡 核心思路：把对象装进集合，序列化整个集合

```java
// 1. 序列化多个对象
Student s1 = new Student("zhangsan", 23, "南京");
Student s2 = new Student("lisi", 24, "重庆");
Student s3 = new Student("wangwu", 25, "北京");

// 2. 装进集合
ArrayList<Student> list = new ArrayList<>();
list.add(s1);
list.add(s2);
list.add(s3);

// 3. 创建序列化流
ObjectOutputStream oos = new ObjectOutputStream(
    new FileOutputStream("myio\\\\a.txt"));

// 4. 一次写出整个集合
oos.writeObject(list);

// 5. 释放资源
oos.close();
```

反序列化
```java
ObjectInputStream ois = new ObjectInputStream(new FileInputStream("myio\\a.txt"));

// 读回来是 Object，强转成 ArrayList<Student>
ArrayList<Student> list = (ArrayList<Student>) ois.readObject();

// 遍历
for (Student stu : list) {
    System.out.println(stu);
}

ois.close();
```

### ⚠️ 关键提醒

| 注意                       | 说明                                       |
| ------------------------ | ---------------------------------------- |
| **集合 + 元素都要可序列化**        | ArrayList 实现 Serializable ✅，Student 也要实现 |
| **一次 writeObject 写整个集合** | 不用循环写，一次搞定                               |
| **读回来强转集合**              | `(ArrayList<Student>) ois.readObject()`  |
| **集合里加新对象后重新序列化**        | 覆盖原文件（写流默认覆盖）                            |
