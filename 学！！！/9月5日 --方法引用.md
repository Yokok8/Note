## 方法引用（入门）

**概念**：把已经有的方法拿过来用，当做函数式接口中抽象方法的方法体。

说人话：Lambda 还能再偷懒 —— 如果 Lambda 体里就是"直接调用某个现成方法"，就把那个方法"贴"过来用。

---
### 📌 使用方法引用的 3 个硬条件

| 条件                           | 含义                                                                   |
| ---------------------------- | -------------------------------------------------------------------- |
| **① 引用处必须是函数式接口**            | 必须有 `@FunctionalInterface`（或只有一个抽象方法的接口）                             |
| **② 被引用的方法必须已经存在**           | 类里写过的方法才能拿过来用                                                        |
| **③ 被引用方法的形参和返回值 跟抽象方法保持一致** | 比如抽象方法是 `int compare(Integer, Integer)`，被引用的方法也得是 `(int, int) → int` |
| **④ 被引用方法的功能要满足当前需求**        | 不能引用一个"功能跑偏"的方法凑数                                                    |


---
## 方法引用 · 完整演化路径

需求：把数组 {3,5,4,1,6,2} 倒序排列

```java
Integer[] arr = {3, 5, 4, 1, 6, 2};

// ① 匿名内部类（最笨）
Arrays.sort(arr, new Comparator<Integer>() {
    @Override
    public int compare(Integer o1, Integer o2) {
        return o2 - o1;
    }
});

// ② Lambda 表达式（去掉匿名内部类的壳）
Arrays.sort(arr, (Integer o1, Integer o2) -> {
    return o2 - o1;
});

// ③ Lambda 简化形式（参数类型 + return + 大括号全不要）
Arrays.sort(arr, (o1, o2) -> o2 - o1);

// ④ 方法引用（最简：现成的 subtraction干的就是这件事）
Arrays.sort(arr, FunctionDemo1::subtraction);
``` 


# 方法引用分类
## ① 引用静态方法

**格式**：`类名 :: 静态方法`
**范例**：`Integer :: parseInt`

---
### 练习：集合中的字符串 →全部转 int

**数据**：`List<String> list = List.of("1", "2", "3", "4", "5");`

#### 完整演化路径（5 个版本，看清"偷懒"过程）

```java
import java.util.function.Function;

List<String> list = List.of("1", "2", "3", "4", "5");

// ① 匿名内部类（最笨）
list.stream().map(new Function<String, Integer>() {
    @Override
    public Integer apply(String s) {
        return Integer.parseInt(s);   // 转 int
    }
}).forEach(s -> System.out.println(s));

// ② Lambda（去掉匿名内部类的壳）
list.stream().map((String s) -> {
    return Integer.parseInt(s);
}).forEach(s -> System.out.println(s));

// ③ Lambda 简化（参数类型 + return + 大括号全去掉）
list.stream().map(s -> Integer.parseInt(s)).forEach(s -> System.out.println(s));

// ④ Lambda 再简化：方法引用 ✅
list.stream().map(Integer::parseInt).forEach(s -> System.out.println(s));

```

输出：`1 2 3 4 5`（全部是整数）


## ② 引用成员方法（3 种）

**格式**：`对象 :: 成员方法`

| 子类 | 写法 | 适用场景 |
|------|------|----------|
| ① **其他类** | `其他类对象 :: 方法名` | 要用某个具体对象的方法（最常见） |
| ② **本类** | `this :: 方法名` | 在本类的成员方法里，引用本类另一个成员方法 |
| ③ **父类** | `super :: 方法名` | 在子类里，引用父类的成员方法 |

###  引用成员方法 · 代码演示

---
#### ① 其他类：其他类对象 :: 方法名（最常见）

```java
// 工具类
public class StringOperation {
    public boolean stringJudge(String s) {
        return s.startsWith("张") && s.length() == 3;
    }
}

// 使用
StringOperation so = new StringOperation();
list.stream()
 .filter(so::stringJudge)               // 对象 :: 方法名
    .forEach(System.out::println);
```

> 🔥 另一个你早就见过的：`System.out::println`

```java
list.stream().forEach(System.out::println);
// 等价于 list.stream().forEach(s -> System.out.println(s));
// System.out 是 PrintStream 类的一个对象，println 是它的成员方法
```

---

#### ② 本类：this :: 方法名

**场景**：在本类的成员方法里，想用本类另一个成员方法。

```java
public class FilterHelper {
    // 业务方法
    public boolean isPositive(int n) {
        return n > 0;
    }

    // 调用方：用 this::isPositive 引用本类自己的方法
    public void filterPositive(int[] arr) {
        Arrays.stream(arr)
            .filter(this::isPositive)   // this :: 方法名
            .forEach(System.out::println);
    }
}

// 使用
new FilterHelper().filterPositive(new int[]{-3, 5, -1, 8, 0, 2});
// 输出：5 8 2
```

> 💡 **注意**：`this::` 只能出现在**非静态方法**里。

想在静态里用，就只能new 本类：：方法名

---

#### ③ 父类：super :: 方法名

**场景**：子类继承父类，子类方法里想调用**父类版本**的方法。

```java
// 父类
public class Parent {
    public void greet() {
        System.out.println("我是父类的问候");
    }
}

// 子类
public class Child extends Parent {
    @Override
    public void greet() {
        System.out.println("我是子类的问候");
    }

    public void callSuperGreet() {
        Runnable r = super::greet;    // super :: 方法名
        r.run();                       // 输出："我是父类的问候"
    }
}

// 使用
new Child().callSuperGreet();   // 输出：我是父类的问候
```

> 💡 **关键场景**：GUI 点击事件里常用 `super::method`，避免触发本类重写后的版本。

---

#### 📌 三种对照表（终极版）

| 子类 | 写法 | 调用者 | 适用场景 |
|------|------|--------|----------|
| **其他类** | `其他类对象 :: 方法名` | 外部对象 | 最常用（如 `System.out::println`） |
| **本类** | `this :: 方法名` | 当前对象 | 在本类方法里引本类另一个方法 |
| **父类** | `super :: 方法名` | 父类对象 | 子类里想"绕开"重写，调用父类版本 |

## ③ 引用构造方法
### 格式
`类名 :: new`
### 范例
`Student :: new`

---
### 练习：把 "张无忌,15" 封装成 Student 对象

#### 第 1 步：先有个 Student 类

```java
public class Student {
    private String name;
    private int age;

    public Student(String name, int age) {  // 关键：有参构造
        this.name = name;
        this.age = age;
    }

    // 省略 getter / setter / toString
}
```

#### 第 2 步：原始数据 + 完整演化

```java
List<String> list = new ArrayList<>();
Collections.addAll(list, "张无忌,15", "周芷若,14", "赵敏,13", "张强,20");

// ① 匿名内部类
list.stream().map(new Function<String, Student>() {
    @Override
    public Student apply(String s) {
        String[] arr = s.split(",");
        return new Student(arr[0], Integer.parseInt(arr[1]));
    }
}).forEach(System.out::println);

// ② Lambda
list.stream().map((String s) -> {
    String[] arr = s.split(",");
    return new Student(arr[0], Integer.parseInt(arr[1]));
}).forEach(System.out::println);

// ③ Lambda 简化（拆出变量，更清晰）
list.stream().map(s -> {
    String[] arr = s.split(",");
    return new Student(arr[0], Integer.parseInt(arr[1]));
}).forEach(System.out::println);

// ④ 方法引用 ✅
list.stream().map(Student::new).forEach(System.out::println);
```

输出：四个 `Student` 对象，姓名+年龄对应正确。



## ④-Ⅰ 使用类名引用成员方法

### 格式
`类名 :: 成员方法`

### 范例
`String :: substring`（特例）
**本节练习**：`String :: toUpperCase`

### 4 大铁律
1. 需要有**函数式接口**
2. 被引用的方法**必须已经存在**
3. 被引用方法的形参，需要跟抽象方法的**第二个形参到最后一个形参**保持一致
4. 被引用方法的功能需要满足当前的需求

### 抽象方法形参的详解（最关键的一段）

#### 第一个参数：
> 表示被引用方法的**调用者**（决定了可以引用哪些类中的方法）

- 在 Stream 流当中，第一个参数一般都表示**流里面的每一个数据**
- 假设流里的数据是字符串，那么用 `String::xxx` 这种方式引用，**只能引用 String 类中的方法**
- 数据是 Integer → 只能引用 Integer 类的方法
- 数据是 Student → 只能引用 Student 类的方法

#### 第二个参数到最后一个参数：
> 跟被引用方法的形参**保持一致**

- 如果抽象方法只有1 个参数（即没有第二个参数），说明被引用的方法需要是**无参的成员方法**



### 局限性：不能引用所有类中的成员方法

跟抽象方法的**第一个参数**有关：
> **第一个参数是什么类型的，就只能引用这个类中的方法。**&#8203;


---
### 练习：把字符串全部转成大写

```java
List<String> list = new ArrayList<>();
Collections.addAll(list, "aaa", "bbb", "ccc", "ddd");

list.stream()
    .map(String::toUpperCase)              // 类名 :: 成员方法
    .forEach(System.out::println);
```

输出：`AAA  BBB  CCC  DDD`


## ④-Ⅱ 引用数组的构造方法

### 格式
`数据类型[] :: new`

### 范例
`int[] :: new`

---

### 练习：集合里的整数，收集到数组中

```java
ArrayList<Integer> list = new ArrayList<>();
Collections.addAll(list, 1, 2, 3, 4, 5);

// ① 匿名内部类
list.stream().toArray(new IntFunction<Integer[]>() {
    @Override
    public Integer[] apply(int value) {
        return new Integer[value];   // value 是流里元素的个数
    }
});

// ② Lambda简化
list.stream().toArray(value -> new Integer[value]);

// ③ 方法引用 ✅
list.stream().toArray(Integer[]::new);

// 转 int[] 同理
list.stream().mapToInt(Integer::intValue).toArray(); // 传统做法
list.stream().toArray(int[]::new); // ❌ 错：int[]::new 不接受 Integer 流
```
