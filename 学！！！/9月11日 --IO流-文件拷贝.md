# 文件拷贝

## 本质
读源文件 + 写目标文件 = 边读边写，把数据"搬"过去

## 核心流程（4 步）
1. 创建输入流（读源文件）
2. 创建输出流（写目标文件）
3. 边读边写（循环：读一个字节 → 写一个字节，直到读完）
4. 关闭两个流

# 文件拷贝 · 方式1（一次一个字节用于小文件）

```java
// 1. 创建对象
FileInputStream fis = new FileInputStream("D:\\\\itheima\\\\movie.mp4");
FileOutputStream fos = new FileOutputStream("myio\\\\copy.mp4");

// 2. 拷贝（核心思想：边读边写）
int b;
while ((b = fis.read()) != -1) {
    fos.write(b);
}

// 3. 释放资源（规则：先开的后关闭）
fos.close();
fis.close();
```

# 文件拷贝 · 方式2 (一次读多个字节用于大文件)

```java
int len;
byte[] bytes = new byte[2]; // 缓冲区开多大，一次就读多少

len = fis.read(bytes); // 第一次读：装 'a','b'，len =2
System.out.println(new String(bytes, 0, len)); // ab

len = fis.read(bytes);             // 第二次读：装 'c','d'，len = 2
System.out.println(new String(bytes, 0, len)); // cd

len = fis.read(bytes);             // 第三次读：装 'e'，len = 1（数组大小2，但只读1个）
System.out.println(new String(bytes, 0, len)); // e
```

buffer = [_, _, _, _, _, _, _, _, _, _]  // 数组大小10
第 1 次 read8 个字节：
[ A, B, C, D, E, F, G, H, _, _]  ← len = 8
第 2 次 read 3 个字节：
[ I, J, K, D, E, F, G, H, _, _]  ← len = 3（后面5 个还是上次的脏数据！）

read( )覆盖修改

```java
FileInputStream fis = new FileInputStream("D:\\a.txt");
byte[] buf = new byte[1024 * 1024 *5]; // 5mb 缓冲区
int len;

while ((len = fis.read(buf)) != -1) {
    System.out.print(new String(buf, 0, len));
}

fis.close();
```

# 文件拷贝 · 方式2（处理异常）

```java
// 1. 创建对象
FileInputStream fis = null;
FileOutputStream fos = null;
try {
    fis = new FileInputStream("D:\\\\itheima\\\\movie.mp4");
    fos = new FileOutputStream("myio\\\\copy.mp4");
    
    // 2. 拷贝
    int len;
    byte[] bytes = new byte[1024 * 1024 * 5]; // 5MB 缓冲区
    while ((len = fis.read(bytes)) != -1) {
        fos.write(bytes, 0, len);
    }
} catch (IOException e) {
    e.printStackTrace();
} finally {
    // 3. 释放资源
    if (fos != null) {
        try {
            fos.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
    if (fis != null) {
        try {
            fis.close();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

# 文件拷贝 · JDK 9 简化版（了解就好）

```java
FileInputStream fis = new FileInputStream("D:\\\\itheima\\\\movie.mp4");
FileOutputStream fos = new FileOutputStream("myio\\\\copy.mp4");

try (fis; fos) {  // ✅ 小括号里写要自动关流的变量
    // 拷贝
    int len;
    byte[] bytes = new byte[1024 * 1024 * 5];
    while ((len = fis.read(bytes)) != -1) {
        fos.write(bytes, 0, len);
    }
} catch (IOException e) {
    e.printStackTrace();
}
// 不用 finally，try 结束自动关流！
```
